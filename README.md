# Godot Game Dev Exercises

A comprehensive collection of mini-projects, prototypes, and game mechanics developed with Godot Engine.

## Description

This repository serves as my personal playground and documentation of my learning journey in game development. It contains various small projects, experiments with physics, UI systems, and AI behaviors designed to strengthen my skills with Godot and GDScript.

The goals of this project are:
* To master GDScript and Godot's node-based architecture.
* To experiment with 2D and 3D physics and animations.
* To create reusable components and UI systems for future games.
* To document the logic behind different game mechanics (platformers, top-down, etc.).

## Project Structure

Each project is contained within its own folder, containing the full Godot project files:
* `/mini-platformer`: Basic 2D platformer mechanics with player controller.
* `/ui-experiments`: Custom menus, inventory systems, and HUDs.
* `/top-down-engine`: Prototypes for top-down movement and combat logic.
* `/shaders-lab`: Custom visual effects and materials.

## Getting Started

### Dependencies

* Godot Engine (I recommend the latest stable 4.x version).
* Basic knowledge of GDScript.
* Optional: A dedicated code editor like VS Code with the "Godot Tools" extension.

### Installing

1. Clone the repository to your local machine:
```
   git clone https://github.com/Frascaz/Game-Development-Exercises.git
```
3. Navigate into the directory:
```
   cd Game-Development-Exercises
```
### Executing program

To run or edit any of these projects:
1. Open the **Godot Engine** project manager.
2. Click on **"Import"** and navigate to the folder of the project you want to explore.
3. Select the `project.godot` file.
4. Once the project is open, press **F5** to run the main scene.

## Help

If the project fails to open, ensure you are using a compatible Godot version (e.g., Godot 4 projects may not open in Godot 3).
Check the **Output** and **Debugger** tabs within Godot if you encounter GDScript errors during runtime.
